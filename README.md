# Blast Mechanical Website Concept

Static concept build for Blast Mechanical, a residential HVAC contractor serving East Houston, the Clear Lake/NASA Corridor, and mainland Galveston County.

## Review status

This repository is for owner review and conceptual deployment. Business details, service claims, membership terms, reviews, forms, and final domain configuration must be verified before the public launch.

The site is prepared as a static GitHub Pages-compatible build. `index.html` is the homepage and all service and service-area routes are included as folders.
